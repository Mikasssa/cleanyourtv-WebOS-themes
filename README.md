# tv-build

Gotowa paczka CleanYourTV z gałęzi theme-glass (commit 0928dc1) do instalacji na TV przez SSH.

`own-icons.sh`: kopiuje Twoje logo z /tmp/logos na TV do folderu icons, dopasowując je do aplikacji po nazwie.

`quiet-screensaver.sh`: wygaszacz LG bez komunikatu „press any button” (install / undo / status).
